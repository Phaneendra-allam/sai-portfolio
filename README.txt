PHANEENDRA CAREER PORTFOLIO
===========================

Files:
- index.html: complete single-file portfolio (HTML, CSS and JavaScript included)
- assets/Phaneendra-Resume.pdf: add your resume PDF here

BEFORE PUBLISHING
1. Open index.html in a text editor.
2. Replace YOUR.EMAIL@example.com, +91 XXXXX XXXXX, LinkedIn and GitHub placeholders.
3. Replace the project GitHub links with your actual repository URLs.
4. Add your resume as assets/Phaneendra-Resume.pdf (create the assets folder if needed).
5. Verify exact certification names and internship details against your certificates.
6. Open index.html in your browser to test.

DEPLOY
GitHub Pages:
1. Create a GitHub repository, for example phaneendra-portfolio.
2. Upload index.html and the assets folder (if you added your resume).
3. In the repository, open Settings > Pages.
4. Under Build and deployment, select Deploy from a branch, choose main and /(root), then Save.
5. Wait for the published URL to appear in Settings > Pages.

This is a static site. The contact form uses mailto and opens the visitor's email app; it does not send or store messages through a server.
